# Apprentissage Google Cloud & BigQuery — Data Analyst

Ce dépôt documente ma montée en compétences sur Google Cloud Platform,
en particulier BigQuery, dans le cadre de mon orientation vers un poste
de Data Analyst / BI.

## Objectif

Maîtriser la chaîne complète de la donnée dans le cloud : stockage,
transformation en SQL, analyse et restitution dans un outil de dataviz
(Power BI et Looker Studio).

## Environnement

- **BigQuery** en mode Sandbox (Google Cloud Platform)
- **SQL** (dialecte GoogleSQL)
- Jeux de données publics BigQuery et données ouvertes françaises (data.gouv.fr)

## Organisation du dépôt

- `notes/` — notes de session : notions abordées, erreurs rencontrées et corrigées
- `requetes-sql/` — requêtes SQL commentées, classées par thème
